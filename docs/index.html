A local-first, open-source Retrieval-Augmented Generation (RAG) application for asking natural-language questions about one or more PDF documents. It extracts selectable text, uses Tesseract OCR for scanned pages, retrieves relevant passages, and generates answers with a local Ollama model and page-level source references.

Get the projectHow it works
🔒

Local-first privacy

PDF processing, embeddings, retrieval, and language-model inference run on your computer. No hosted LLM API is required.

📖

Page-aware answers

Retrieves relevant passages and shows source filenames and page numbers so answers can be checked against the original documents.

🔎

Scanned PDF OCR

Uses Tesseract OCR when a page has little or no embedded text, supporting image-only and scanned PDFs in English by default.

🪶

Lightweight local stack

Uses Streamlit, PyMuPDF, Sentence Transformers, NumPy, and Ollama. Compact models are a practical starting point for an 8 GB RAM computer.

The workflow

From document to answer

01

Upload

Choose one or more PDFs in the local app.

02

Extract

Read embedded text or OCR scanned pages, then create page-aware chunks.

03

Retrieve

Create local embeddings and find passages relevant to the question.

04

Answer

Ask the local Ollama model to generate an answer grounded in retrieved passages.

Quick start

Run it locally

Install Python dependencies, Ollama with a model, and the Tesseract application with English language data. Then start the Streamlit interface.

ollama pull qwen2.5:0.5b
python -m venv .venv
# Activate the environment, then:
python -m pip install -r requirements.txt
python -m streamlit run app.py

See the README for complete Windows, macOS, and Linux installation instructions, OCR setup, configuration, and offline preparation. The first setup requires internet access to download packages and model weights; after these are cached, document processing and local inference can run offline.
