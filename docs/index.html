Quick start

Run it locally

Install Ollama and download the compact model once, then launch the browser interface.

ollama pull qwen2.5:0.5b
python -m venv .venv
pip install -r requirements.txt
streamlit run app.py

First setup requires internet to download dependencies and model weights. After setup, inference and document processing run locally.
